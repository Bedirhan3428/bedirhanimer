## 🏗️ Architecture Overview

This repository contains the source code for my personal portfolio. Designed with a strict "Dark Architectural" aesthetic, it serves not just as a resume, but as a live demonstration of my design philosophy: clean systems, logical flow, and high performance.

### Tech Stack
- **Framework:** `React` + `Vite`
- **Styling:** `Tailwind CSS` (Custom Dark Mode Configuration)
- **Icons:** `Lucide React`
- **Deployment:** `Vercel`

## 🚀 Features

- **Dark Architectural Theme:** A custom dark mode (`#09090B` background) designed to reduce eye strain while highlighting key elements with vibrant soft-green accents.
- **Interactive JS Terminal:** Features an in-app React modal mimicking a terminal execution to demonstrate logical flow.
- **Dynamic CSS Grid:** A custom background grid pattern built purely with CSS linear gradients.
- **Fully Responsive:** Seamless layout transitions from mobile to desktop.

## 💻 Local Development

To run this project locally:

### 1. Clone the Repository
```bash
git clone https://github.com/Bedirhan3428/bedirhanimer.git
cd bedirhanimer
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
*Application will be available at `http://localhost:5173`.*
